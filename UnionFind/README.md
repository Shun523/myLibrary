# UnionFind(C)
競技プログラミングでよく用いられるUnionFindというデータ構造を実装しました。主にグラフの接続判定に使用されます。

## 実行方法
```
cd UnionFind
make
make asan

```

## なぜ作ったか
コンテストでは既存のライブラリを使うだけで、最近中身の挙動があまりイメージできなくなってきたので、復習を兼ねてC言語で実装しました。C++と違いSTLに頼れないので、malloc/freeでのメモリ管理も自分でやりました。

グラフの接続判定はもちろん、二部グラフの判定などにも利用でき、問題によってはUnionFind構造体に新たな配列をもって適切に更新することが必要な場面もあるので実装を再確認できてよかったです。
